这个小窝是怎么搭起来的

2026.11.03 约 6 分钟 标签：日志 / 前端 / Cloudflare

一开始没有「小窝」这个概念，只有一台拆开的无人机。 后来东西越攒越多，才想着搭个门面把它们收起来。这篇把这几天做过的事、推翻过的东西、踩到的坑都记一下， 以后回头能看懂当时在想什么。

第一步：先有一个能转的东西

最初做的是 AIR 3S 三维拆解实验室：一台用代码现场生成几何体的无人机， 点一下云台、电池、图传核心，它会自己飘出来。整页只有三个文件，index.html、styles.css、 app.js，加一份本地托管的 three.min.js。

它本身是个单页应用，只有根路径。/lab/ 这个目录是后来挪的——为了给导航页腾地方。 搬完之后所有相对路径（./styles.css、./vendor/three.min.js）都不用改，因为它们本来就是相对的。

第二步：第一版门面，樱花粉

第一版导航页是粉色系：樱花飘落、圆滚滚的卡片、一只眨眼的小猫、贴纸一样的按钮。 所有卡片都从一个数组里渲染出来，加内容就是加一条： 

{
  id: "air3s",
  title: "AIR 3S 拆解实验室",
  url: "./lab/",
  tag: "3D 实验室",
  emoji: "🚁",
  ready: true
}

可爱是可爱，但看久了会觉得「门面」和「里面」是两套气质：外面是马卡龙，进去是冷色调的实验室。 所以有了第三版。

第三步：换成云海森林

现在的首页是这样的：深绿的云层、细密的雨丝、底部一层雾，中间一句「欢迎来到我的小窝」。 标题用黑体，引文用宋体，右上角能切深浅色，右下角那个调色盘可以把整站主色换成樱粉或雾蓝。

晨光不问赶路人，时光不负有心人。

技术上说没什么新鲜的：CSS 径向渐变画云、filter: blur() 让它软下来、 一条 repeating-linear-gradient 做雨丝、mask-image 做渐隐。 真正花时间的是调数值——云的位置、雾的浓度、字和背景的对比度，改了三十多次才不刺眼。

第四步：留言板，先后端换了两次

第一版想用 giscus（基于 GitHub Discussions）。方案很干净：不用服务器、不用数据库， 缺点是留言必须登录 GitHub 账号。代码写完、仓库 Discussions 也开了，最后卡在「应用没装到仓库」这一步。

后来想清楚了：这个站是给所有人看的，不是只给会写代码的人看的。那就自己写后端。

现在的留言板是 Cloudflare Worker + KV： 

GET    /api/messages?limit=60      取留言（新的在前）
POST   /api/messages               发留言 {"name","text","mood"}
DELETE /api/messages/<id>          删留言（X-Admin-Token）
GET    /api/health                 健康检查

匿名就能发，不用注册。规则都写在 Worker 里：名字 24 字、内容 500 字、每条最多一个链接、 同 IP 五分钟五条、蜜罐字段拦机器人。内容原样存进 KV，渲染的时候前端统一转义，所以 <script> 打不进来。

踩到的坑：KV 是最终一致的

本地测的时候一切正常，上线后发了条留言，列表里没有。查了半天才想起来—— Cloudflare KV 的 list 操作有几十秒延迟，实测这次是 30 秒左右。

处理办法很土但有效：发出去之后先把这条塞进本地列表，标上「刚刚 · 发送成功」， 然后 20 秒、45 秒各自动重新拉一次，等服务器列表里出现了，就把本地那条去掉。 发的人不会以为「我是不是没发出去」。

想彻底解决就得换 D1（SQL，强一致）。记在这儿，哪天有空再折腾。

现在的结构

路径是什么
/云海首页，所有入口在这
/lab/AIR 3S 三维拆解实验室
/guestbook/匿名留言板（Worker + KV）
/gallery/相册，点开能看大图
/posts/就是这里

一些想法

  • 页面全是手写的 HTML / CSS / JS，没有框架、没有构建步骤，改完推上去 Cloudflare 自己部署。
  • 每加一个东西，就多一个目录，首页多一张卡。导航页只做一件事：让人一眼看到有什么。
  • 慢一点没关系，别把东西堆在草稿里。写着写着就成型了。
