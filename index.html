这个窝是怎么来的

一开始只是想放一个能转的 3D 模型，后来发现 Fun 的东西越攒越多，干脆搭成一个窝。 现在它是「作品 + 记录 + 一点点碎碎念」的组合，样子会慢慢变。

页面全部是手写 HTML / CSS / JS，没有框架、没有外部资源，打开就能跑。 想加新东西的时候，只要在这里多放一个入口就好。
