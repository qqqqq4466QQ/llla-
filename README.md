# DJI Air 3S — 3D 结构拆解实验室

一个完整、可交互的 DJI Air 3S 三维拆解可视化页面。模型、云台、机臂、电机、螺旋桨、电池、视觉传感器与航电核心全部由 JavaScript / Three.js 程序化生成，**不依赖任何外部 3D 模型文件**。

![整机视图](assets/air3s-assembled.png)

## 运行

无需安装依赖，直接双击打开 `index.html` 即可。页面内置本地 `vendor/three.min.js`，完全离线可用。

也可以使用任意静态服务器：

```bash
python -m http.server 8033
# 打开 http://127.0.0.1:8033/
```

推荐使用 Chrome / Edge / Firefox 等支持 WebGL2 的现代浏览器。

## 交互功能

- **点击拆解**：点击模型部件或左侧清单，部件会沿预设轨迹分离，并弹出详情面板。
- **自由视角**：拖拽旋转、滚轮缩放；触屏设备支持单指旋转、双指缩放。
- **全部拆解 / 全部装回**：一键展开九个模块，并自动拉远镜头以完整容纳爆炸视图。
- **发光高亮**：选中部件带有动态轮廓光、3D 光晕、琥珀色锁定框与引线标注。
- **部件标注**：拆解后自动显示中文名称与关键参数，并随视角实时避让、重新布线。
- **参数详情**：右侧面板展示双摄、电池、图电核心、感知系统等模块的详细规格。
- **自动旋转**：默认以慢速环绕，开始交互后自动暂停，可随时重新开启。
- **响应式布局**：桌面端双侧信息面板；平板与手机端收纳为抽屉/底部详情卡。

### 快捷键

| 按键 | 功能 |
| --- | --- |
| `Space` | 全部拆解 / 全部装回 |
| `R` | 一键复位 |
| `A` | 开关自动旋转 |
| `Esc` | 关闭详情、收起抽屉 |

### 可分享的直达状态

- `index.html?exploded=1`：打开即呈现完整爆炸视图。
- `index.html?exploded=1&part=gimbal`：爆炸视图并锁定双摄云台。
- `part` 可替换为 `gimbal`、`vision`、`battery`、`core`、`frontArms`、`rearArms`、`motors`、`props`、`body`。

## 文件结构

```

app.js                      程序化建模、交互、动画、标注与数据
vendor/three.min.js         Three.js r160（本地离线）
assets/                     预览截图
```

## 技术说明

- **程序化几何**：机身使用自定义超椭圆截面 loft 几何；其余零件由圆角盒、圆柱、环、管与自定义挤出桨叶组合而成。
- **材质与光照**：PBR 金属/复合材质、程序化环境贴图、方向光 + 轮廓光 + 点光、软阴影与雾效。
- **自定义相机控制**：球坐标轨道相机、惯性阻尼、自动环绕、双指缩放，无额外控制器依赖。
- **拾取与高亮**：Raycaster 命中层级向上追溯到部件；每个部件拥有独立背面轮廓光与屏幕空间锁定框。
- **实时标注**：三维锚点投影到屏幕空间，配合 `requestAnimationFrame` 更新、碰撞避让和 SVG 贝塞尔引线。
- **无外部资源**：没有外部模型、贴图、字体或 CDN 请求，断网也能完整运行。

## 数据说明

页面中的重量、尺寸、影像、电池与图传参数依据 DJI Air 3S 公开规格整理，仅用于交互式结构展示，非官方产品页面。三维外形为代码重制的艺术化结构模型。
